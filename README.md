# Lunahan

A bilingual Turkish–English AI assistant web application.

## MVP scope

- Automatic Turkish/English language selection
- Manual language switch
- Inbox summary experience
- AI-assisted email drafting
- Explicit user approval before sending anything

## Run locally

This first prototype is dependency-free. Open `index.html` in a browser.

## Security principle

Lunahan must never send an email or perform an external action without explicit user approval.
